# Assignments

Four assignments, 10% of the grade together, plus the [term project](project.md) (25%).
Your own work goes in `assignments/<term>-<you>/` (for example
`assignments/2026-2027-fall-efe-kurucay/hw-01/`) — copy the template below into it
when an assignment is issued. Material whose author is not known goes in
`assignments/<term>-unattributed/`.

Use a lowercase, hyphenated folder name — `efe-kurucay`, not `Efe Kuruçay`.
