Question 1 — Modeling10 points

(a) Model (6 pts: variables 1, objective 2, constraints 3)

x1 = desks produced per week, x2 = bookshelves produced per week.

maxz = 40x1 + 30x2(profit, ×100 TL)
s.t.2x1 + x2 ≤ 100(CNC hours)
x1 + x2 ≤ 80(assembly hours)
x1 ≤ 40(desk demand)
x1, x2 ≥ 0
(b) Classification (4 pts)

Linear: the objective and every constraint are linear in x, so this is an LP.

Continuous if fractional production is allowed (e.g. weekly averages). If whole units are required it becomes an integer LP. Here the LP optimum happens to be integral anyway.

Convex feasible set: each constraint defines a half-space, and an intersection of half-spaces (a polyhedron) is convex.

Question 3 — Duality and Sensitivity15 points

(a) Dual (5 pts)
minw = 100y1 + 80y2 + 40y3
s.t.2y1 + y2 + y3 ≥ 40(x1 column)
y1 + y2 ≥ 30(x2 column)
y1, y2, y3 ≥ 0
(b) Complementary slackness (6 pts)

The demand constraint is slack at the optimum (s3 = 20 > 0), so y3 = 0.

Both x1 = 20 > 0 and x2 = 60 > 0, so both dual constraints must be tight:

2y1 + y2 = 40, y1 + y2 = 30 ⇒ y1 = 10, y2 = 20

y* = (10, 20, 0). Strong duality: w* = 100·10 + 80·20 + 40·0 = 2600 = z* ✓

Shortcut: the same numbers appear under s1, s2, s3 in the z-row of the final tableau.

(c) Shadow prices (4 pts)

CNC offer: reject. One extra CNC hour is worth y1* = 10, which is less than its price of 15, so each hour would lose 5.

Assembly offer: accept. One extra assembly hour is worth y2* = 20, which is more than its price of 15, so each hour gains 5. This holds only while the current basis stays optimal.

Question 4 — Mathematical Foundations15 points

(a) Norms (3 pts)

‖v‖1 = 1 + 2 + 2 = 5, ‖v‖2 = √(1 + 4 + 4) = 3, ‖v‖∞ = 2.

The ℓ1 unit ball is a diamond (a square rotated 45°) with vertices (±1, 0), (0, ±1).

(b) Gradient and Hessian (4 pts)

∇f(x, y) = (2x − 2y + ex, −2x + 4y), ∇²f(x, y) = [[2 + ex, −2], [−2, 4]]

At (0,0): ∇f = (1, 0), ∇²f = [[3, −2], [−2, 4]], f(0,0) = 1.

(c) Strict convexity (4 pts)

Second-order condition: f is strictly convex if ∇²f(x) ≻ 0 for every x. Check the leading principal minors (Sylvester):

D1 = 2 + ex > 0, D2 = 4(2 + ex) − 4 = 4 + 4ex > 0 for all x.

So ∇²f ≻ 0 on all of ℝ², and f is strictly convex.

Alternative proof: x² − 2xy + 2y² = (x − y)² + y², a sum of convex functions, and eˣ is strictly convex.

(d) Taylor model (4 pts)

m(p) = f(0) + ∇f(0)ᵀp + ½ pᵀ∇²f(0) p

m(p) = 1 + p1 + ½(3p1² − 4p1p2 + 4p2²) = 1 + p1 + 1.5p1² − 2p1p2 + 2p2²

(c) (3 pts)

Each coordinate updates independently: xi ← (1 − αλi) xi. The method converges iff |1 − αλi| < 1 for every i, which gives 0 < α < 2/λmax = 0.2.

With α = 0.25: the x1 factor is 1 − 0.5 = 0.5, so that coordinate shrinks. The x2 factor is 1 − 2.5 = −1.5, so x2 flips sign and grows by 1.5× every iteration. The iteration diverges.

Question 6 — Newton and Quasi-Newton Methods10 points

(a) Newton step (6 pts)

Solve ∇²f Δx = −∇f with ∇²f = [[3, −2], [−2, 4]] and ∇f = (1, 0).

det = 12 − 4 = 8, (∇²f)−1 = (1/8)[[4, 2], [2, 3]].

Δxnt = −(1/8)(4, 2) = (−1/2, −1/4).

Check: 3(−½) − 2(−¼) = −1 ✓, −2(−½) + 4(−¼) = 0 ✓.

Newton decrement: λ² = ∇fᵀ(∇²f)−1∇f = 4/8 = 1/2, so λ = 1/√2 ≈ 0.707.

Predicted decrease: m(0) − m(Δxnt) = λ²/2 = 1/4. The actual value is f(−½, −¼) = 0.7315, a decrease of 0.2685, which is close to the prediction.

(b) Quasi-Newton (4 pts)

Forming the Hessian takes O(n²) second derivatives, which are often unavailable or expensive. Solving the Newton system then costs O(n³). BFGS builds a Hessian approximation from gradient differences only and costs O(n²) per iteration.

Secant condition: Bk+1 sk = yk, where sk = xk+1 − xk and yk = ∇f(xk+1) − ∇f(xk).

The curvature condition skᵀyk > 0 (guaranteed by a Wolfe line search) keeps Bk+1 positive definite.

Question 7 — Lagrange Multipliers and KKT15 points

(a) KKT (4 pts, 1 per condition)

Write the constraint as g(x, y) = 5 − x − 2y ≤ 0. Lagrangian: L = x² + y² + μ(5 − x − 2y).

1. Stationarity: 2x − μ = 0, 2y − 2μ = 0

2. Primal feasibility: x + 2y ≥ 5

3. Dual feasibility: μ ≥ 0

4. Complementary slackness: μ(5 − x − 2y) = 0

(b) Solve (7 pts)

Case μ = 0: stationarity gives x = y = 0, but then 0 ≥ 5 is false. Infeasible, so no solution in this case.

Case μ > 0: the constraint is active, x + 2y = 5. Stationarity gives x = μ/2 and y = μ, so μ/2 + 2μ = 5 and μ = 2.

(x*, y*) = (1, 2), μ* = 2 ≥ 0 ✓, f* = 5.

Global: the objective is convex (∇²f = 2I ≻ 0) and the constraint is affine, so the problem is convex and the KKT conditions are sufficient. Slater's condition also holds, e.g. (5, 5) is strictly feasible. Geometrically, (1, 2) is the projection of the origin onto the line x + 2y = 5, along its normal (1, 2).

(c) Sensitivity (4 pts)

The multiplier is the rate of change of the optimal value with the right-hand side: ∂f*/∂b = μ* = 2.

Estimate: f*(5.2) ≈ 5 + 2·0.2 = 5.4.

Exact: the optimum is (b/5)(1, 2), so f*(b) = b²/5 and f*(5.2) = 27.04/5 = 5.408. The error of 0.008 comes from the curvature of f*(b), which the first-order estimate ignores.
